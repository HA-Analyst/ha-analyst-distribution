# HA Analyst Beta

HA Analyst ist eine Informations-, Analyse- und Wissensschicht für Home Assistant. Er erzeugt aus Home-Assistant-Daten einen strukturierten Hausüberblick und stellt diesen über das verwaltete Analyst-Dashboard bereit.

Diese Distribution enthält keinen offenen Analyst-Core-Quellcode. Der Analyst läuft als vorgebauter nativer Runtime-Container für `amd64` und `aarch64`.

Die externe Beta befindet sich in Release-Vorbereitung. Installation, Voraussetzungen und Beta-Hinweise stehen in `DOCS.md`. Support und Feedback werden über die GitHub Issues des HA-Analyst-Distributionsrepositories gesammelt.
